# Active Learning Sims

Beginner classroom simulations for practicing 12 collaborative active learning techniques:
Think-Pair-Share, Pair-Square-Share, Chain Notes, Peer Review, Case Studies, Send a Problem,
Jumbled Sequence, Human Tableau, Jigsaw, Gallery Tour, Four Corners, and Fishbowl.

Each simulation walks through the steps of the technique, sends the facilitator to visit groups
in a virtual classroom, and asks them to make teaching decisions with feedback.

## How to use

Open `index.html` in a browser, or view it through GitHub Pages.
Link straight to one technique by adding its name after `#`, for example `.../#four-corners`.

The whole site is a single HTML file. It needs no build step and no server.
